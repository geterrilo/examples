# Errilo examples

Examples to copy for [Errilo](https://errilo.com), the error tracker compatible with the Sentry SDKs.

- [`auto-fix/`](auto-fix/): a GitHub workflow that fixes new errors and regressions with Claude Code, the Errilo MCP server and the [Errilo Auto-fix action](https://github.com/geterrilo/autofix), then opens a pull request.
